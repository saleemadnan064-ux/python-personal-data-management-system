# Personal Data Management System

A Python-based Personal Data Management System designed to store, manage, search, and organize personal records through a simple and user-friendly interface.

## Features

* Add new personal records
* View saved records
* Edit existing records
* Delete records
* Search personal records
* Store data using a local database
* User-friendly graphical interface
* Simple and easy-to-use data management

## Technologies Used

* Python
* PyQt5
* SQLite
* Object-Oriented Programming

## Personal Information Fields

The system can manage information such as:

* Full Name
* Father Name
* Date of Birth
* Gender
* Phone Number
* Email
* Address
* City
* Education
* Occupation

## Project Purpose

This project was created as a Python programming and GUI development project. It demonstrates database management, graphical user interface development, CRUD operations, searching, and basic software development concepts.

## Database

The project uses SQLite to store records locally. No external database server is required.
